# Restometry Landing Page

A professional Next.js landing page for Restometry, a restaurant labor management software. This single-page application showcases the Phase 1 features designed to help restaurant owners optimize labor costs and improve operational efficiency.

## Features Highlighted

### Phase 1 Core Features
- **Smart Scheduling (Basic Version)** - Manual shift creation with AI-powered recommendations
- **Attendance Tracking (Basic)** - Time-in/time-out logs with overtime tracking
- **Labor Cost Calculator** - Real-time labor cost percentage monitoring
- **Simple Dashboard Home** - High-level performance overview
- **Daily Sales Entry & Update** - Manual sales data management

## Tech Stack

- **Next.js 15** - React framework with App Router
- **TypeScript** - Type safety and better development experience
- **Tailwind CSS** - Modern, responsive styling
- **Lucide React** - Clean, professional icons
- **ESLint** - Code quality and consistency

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

## Design Principles

- Professional and clean interface
- Clear value propositions for each feature

- Reduce labor costs by up to 30%
